# MiniRSS 1.3.0

Компактная RSS-читалка для Windows 10/11 в стиле Fluent Design.

## Возможности проекта
- RSS и Atom, подписки, поиск, избранное.
- Светлая и тёмная темы, компактный режим, прозрачность.
- Системный трей, автозапуск и уведомления.
- Интернет-обновления через GitHub Releases с проверкой SHA-256.

## Состояние публикации
В репозиторий уже добавлен workflow Windows-сборки:
`.github/workflows/publish-release.yml`

**Исходный ZIP-архив приложения пока не добавлен.** Чтобы сборка и выпуск заработали, загрузите в корень репозитория файл:
`MiniRSS_Windows_Project_v1.3.0_upload.zip`

Затем создайте и отправьте тег `v1.3.0`. GitHub Actions распакует проект, установит зависимости, запустит тесты, соберёт `MiniRSS.exe` и опубликует ZIP обновления с SHA-256 в GitHub Releases.

## Сборка вручную
После распаковки исходного архива на Windows запустите `minirss_windows/build_exe.bat`.
