# MiniRSS 1.4.6

Компактная RSS/Atom-читалка для Windows 10/11.

## Установка

Скачайте **MiniRSS_Setup_1.4.6_x64.exe** со страницы GitHub Releases и запустите установщик. Установка выполняется в профиль текущего пользователя и обычно не требует прав администратора.

В установщике можно оставить отмеченным пункт «Создать ярлык на рабочем столе». Также можно создать ярлык в меню «Пуск». После установки приложение можно сразу запустить. Настройки и подписки хранятся отдельно в `%APPDATA%\\MiniRSS` и не удаляются при деинсталляции.

## Возможности

- RSS и Atom, подписки, поиск, избранное и автоматическое обновление.
- Отдельная тема **iOS 27 · Liquid Glass** с контурными иконками, плавающей стеклянной док-панелью, бликами на поверхностях и Mica на Windows 11. Для неё есть светлый/тёмный режим и переключение «Прозрачный / Однотонный».
- Готовые источники новостей из Казахстана, русскоязычных и мировых СМИ, технологий и науки.
- В технологической подборке: Rozetked и iGuides через Google Новости, 4PDA через RSS.
- Компактный режим, прозрачность, режим «поверх окон», системный трей, автозапуск и уведомления.
- Автообновление через SHA-256-проверенный установщик: ожидание закрытия всех процессов MiniRSS, определение необходимости UAC для защищённых папок, установка поверх текущей версии, повторный запуск и журнал в %APPDATA%\\MiniRSS\\update.log.

## Сборка

На Windows установите Python 3.10+ и зависимости из `requirements.txt`, затем запустите `build_exe.bat`. Для создания установщика дополнительно установите Inno Setup 6 и выполните `iscc setup.iss`.

GitHub Actions автоматически собирает EXE, ZIP-пакет и установщик Inno Setup при публикации коммита в main или тега версии.
