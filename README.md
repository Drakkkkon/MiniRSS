# MiniRSS 1.3.0

Компактная RSS-читалка для Windows 10/11 в стиле Windows 11 Fluent Design.

Полный исходный проект находится в архиве `MiniRSS_Windows_Project_v1.3.0.zip`. В архиве есть исходный код, инструкции, тесты, иконка приложения и workflow сборки Windows EXE.

## Возможности
- RSS 2.0, RSS 1.0/RDF и Atom
- Избранное, поиск и категории источников
- Светлая и тёмная темы, компактный режим и прозрачность
- Системный трей, автозапуск и уведомления
- Проверка и установка обновлений через публичные GitHub Releases

## Сборка
Распакуйте архив, перейдите в папку `minirss_windows` и запустите `build_exe.bat` на Windows.

## Релизы
Сборка и публикация Windows-релизов выполняется GitHub Actions по тегам `v*.*.*`. См. `GITHUB_SETUP.md` внутри архива.
